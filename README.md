# SnoreGuard / 鼾声守护

一个无需 Root、Shizuku 或联网权限的原生 Android 小工具：使用**手机内置麦克风**在本地检测疑似鼾声，按设定上限小步提高**系统媒体音量**，连续安静后再逐格恢复。白噪声可以继续由网易云等应用通过耳机播放。

## V1.1 功能

- 16 kHz 单声道实时声学分析；开始时采集 32 帧、约 **2.05 秒**背景声音，对每帧 dB 取算术平均。
- 根据相对背景音量、低频能量、过零率与连续帧识别疑似鼾声；不保存原始音频。
- 音量提高与恢复均每 **1.5 秒最多变化 1 格**；可设目标增幅、上限和安静恢复时间。
- 麦克风类型前台服务、常驻通知与唤醒锁，支持应用退到后台和锁屏后继续工作。
- 默认请求内置麦克风，并检查实际录音路由；系统路由到耳机或外部麦克风时停止并提示。
- 不申请音频焦点，不发送媒体控制命令，不暂停或切断网易云播放。
- 本地夜间日志：启动、校准、疑似鼾声、每次音量变化、恢复、停止与错误；最多 500 条。
- 日志页支持查看、清空和导出 UTF-8 TXT；导出使用系统文件选择器，不需要存储权限。
- 无 `INTERNET` 权限；日志和设置只保存在本机。
- 鼾声识别为轻量启发式，并非医疗诊断；白噪声、环境和手机麦克风差异会影响准确率。

## 安装与使用

1. 使用 Android 8.0（API 26）或更高版本手机。
2. 安装签名 APK，允许麦克风与通知权限。
3. 先启动网易云白噪声，再打开本应用。保持“固定使用手机内置麦克风”开启。
4. 建议先用目标增幅 1–2 格、上限 50–70% 试用，避免音量过大。
5. 开始检测后的约 2 秒用于背景校准；保持白噪声处于正常播放状态。
6. 如手机系统限制后台运行，请在系统设置中允许本应用后台运行/忽略电池优化。
7. 醒来进入“查看夜间日志”检查事件，可导出 TXT 或清空。

## 从源码构建

要求：JDK 17、Android SDK Platform 35、Build Tools 35。

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
# 发布构建需要自行配置签名；不要将密钥提交到仓库。
./gradlew assembleRelease
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。也可以在 Android Studio 中打开项目并运行到真机。

项目不依赖 AndroidX，使用 Java 原生 Activity/Service。应用 ID 为 `com.local.snoreguard`，当前版本为 V1.1（versionCode 2）。
