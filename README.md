# 鼾声守护 SnoreGuard

一款本地运行的 Android 鼾声检测与媒体音量调节应用。检测到疑似鼾声后自动提高媒体音量，连续安静一段时间后恢复原音量。当前版本：V1.2（versionCode 3）。

## 功能

- 锁屏和后台持续检测，使用麦克风前台服务。
- 默认指定手机内置麦克风，并检查实际录音路由，避免误用耳机麦克风。
- 只调整系统媒体音量，不申请音频焦点，不控制第三方音乐播放。
- 可调整检测灵敏度、目标增幅、自动提高上限及恢复时间；上限直接按手机实际媒体音量格数设置，不使用百分比换算；提高和恢复均为每 1.5 秒最多变化 1 格。
- 启动时采集 32 帧（约 2.05 秒）背景声音，对各帧 dB 取算术平均值。
- 夜间日志页记录校准、疑似鼾声、逐格音量变化和恢复事件，支持清空与导出 TXT，最多保留最近 500 条。
- 音频仅在本机逐帧分析，不保存录音，不申请互联网权限。
- 无需 Root、Shizuku 或 ADB。

## 使用

1. 在网易云音乐等应用中正常播放白噪声，可使用耳机收听。
2. 打开鼾声守护并允许麦克风权限。
3. 保持默认的“手机内置麦克风（推荐）”。
4. 点击“开始检测”，前约 2 秒保持正常播放以学习环境底噪。
5. 不再需要时，在应用或常驻通知中点击“停止并缓慢恢复”。
6. 醒来后在主页点击“查看夜间日志”，可按时间查看事件或导出 TXT。

## 构建

- Android 8.0（API 26）及以上。
- 使用 Android Studio 打开本仓库根目录。
- 安装 Android 35 SDK，使用 JDK 17 构建。
- Android Gradle Plugin 8.7.3，Gradle 8.9。

命令行构建：

```bash
gradle testDebugUnitTest assembleRelease
```

发布构建输出为未签名 APK，需要自行签名后安装。请勿将签名密钥或密码提交到仓库。

## 权限与隐私

仅申请麦克风、前台服务、麦克风前台服务、通知和保持运行所需权限。无联网权限，音频不保存、不上传。

## 限制

鼾声判断采用轻量声学特征算法，可能出现误判或漏检，不是医疗级识别或诊断。白噪声会被手机麦克风收录，误检较多时可降低灵敏度。部分厂商设备可能限制麦克风路由或后台运行，需要在系统设置中允许后台运行或关闭电池优化。
